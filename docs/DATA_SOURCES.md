# Data sources

Every input to the simulation carries one of three labels: **REAL DATA** (measured data
used directly), **CALIBRATED TO REAL DATA** (model parameters tuned so outputs match
published measurements), or **SIMULATED** (generated by the model with no direct
external basis).

| Dataset | Used for | Licence | Label | Known limitations |
|---|---|---|---|---|
| NASA POWER hourly, Lucknow (26.85° N, 80.95° E), 2023: all-sky surface irradiance and 2 m air temperature. Fetched by `data/download_nasa_power.py`, processed to `data/processed/weather_lucknow_2023.csv` | Rooftop PV output, day types (clear / cloudy / monsoon / heatwave), seasonal load scaling | NASA open data (no restrictions) | REAL DATA | Satellite/reanalysis estimate (~50 km grid), not a ground station. Hourly averages are held flat within each hour. Horizontal irradiance slightly understates tilted-module output. |
| Prayas eMARC published load patterns (energy.prayaspune.org/electricity-load-patterns) | Calibration targets for household load segments (`config/load_segments.yaml`) | Published figures, cited | CALIBRATED TO REAL DATA | Only aggregate figures are used: night and 21:00 load of a typical home, peak of AC-owning and water-heater-owning homes. The split into low-income / middle / affluent segments and all appliance-level parameters are assumptions. eMARC homes are a small, non-random sample. |
| Prayas ESMI, "ESMI in Uttar Pradesh" (2016–19 monitoring locations), published summary | Baseline outage calibration: daily and evening (17:00–23:00) outage minutes, outages per day, duration mix (`config/saanjh.yaml`, `outage_calibration`) | Published figures, cited | REAL DATA (aggregated) | Category averages (megacity / other municipal / rural), not per-location distributions. The blog notes the locations are not fully representative of districts. The share of outages caused by supply shortfall rather than faults is an assumption (0.5, varied in sensitivity runs). |
| Prayas ESMI minute-wise voltage data, Harvard Dataverse doi:10.7910/DVN/CLLZZM (2014–2019) | Optional per-location outage statistics via `data/load_esmi.py` (outage = voltage < 130 V) | CC0 1.0 | REAL DATA | Download requires a guestbook form, so it is not fetched automatically. When `data/processed/esmi_stats.json` exists, it replaces the published summary figures. `data/samples/esmi_format_fixture.csv` is a **synthetic** format fixture for tests only. |
| UCI Individual Household Electric Power Consumption (one household near Paris, 2006–2010) | Forecasting benchmark only (XGBoost one-step model in `ai_forecasting/`) | CC BY 4.0 | REAL DATA, **non-Indian** | One French household. Not used to model Indian demand. |
| Household appliances, ownership, inverter and actuator shares | Load generation, flexibility | — | SIMULATED / ASSUMPTION | Inverter ownership is set per segment (low-income 2%, middle 20%, affluent 50%), consistent with the IIT Madras finding of 4–5% overall ownership concentrated among affluent homes. |
| Feeder and transformer parameters | Power flow, loading | — | ASSUMPTION | Lumped balanced LT feeder; no per-phase imbalance. |

## How to refresh

```bash
python data/download_nasa_power.py --lat 26.85 --lon 80.95 --year 2023 --name lucknow
python simulation/weather.py --site lucknow --year 2023
python scripts/calibrate_loads.py
# optional, after a manual ESMI download into data/raw/esmi/:
python data/load_esmi.py --locations Lucknow
```
